<h3 align="center">Stay afloat. Ready for any wind.</h3>

<p align="center">Open-source developer tools that find what is about to break in your software,<br>show exactly where, and help you or your coding agent fix it first.</p>

---

| Project | What it does | Status |
|---|---|---|
| [**Evergreen**](https://github.com/arminazimi/evergreen) | Finds end-of-life runtimes, deprecated packages and retired GitHub Actions, at file and line, with a source for every finding. | released · [npm](https://www.npmjs.com/package/evergreen-deprecation) |
| [**Seaworthy**](https://github.com/arminazimi/seaworthy) | Checks any built static site and reports what AI agents cannot read, with locations and fix hints. | alpha |
| [**Slipway**](https://github.com/arminazimi/slipway) | An RTL-ready theme and spec for GitHub Pages sites that agents can edit safely. | alpha |
| [**Oakum**](https://github.com/arminazimi/oakum) | Checks that a change keeps state consistent across database, cache and broker. | planning |

```bash
npx evergreen-deprecation scan   # every lifecycle risk in this repository, with file, line and source
```

### How we build

- **Exact.** Every finding points to a file and a line.
- **Sourced.** Every claim links to where it came from.
- **Honest.** Nothing unknown is reported as safe.
- **Local-first.** Runs on your machine. No account needed.

### Why Velella

*Velella* is a small blue sailor of the open ocean. What looks like one animal is a colony: many polyps sharing one float and one sail. It comes in two mirror-image forms, so whichever way the wind blows, part of the colony is ready for it. Our projects work the same way: small, each with one job, sharing one way of working.
